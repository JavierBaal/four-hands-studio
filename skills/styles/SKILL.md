# Styles atlas

Load only the file for the style you need. Each file has the same sections: what defines it, typical moves and how to write them with the Four Hands tools, clichés to avoid (the neighbouring genre it slides into), how users ask for it, and sound (what to do with the built-in sounds and what to leave annotated for the user's libraries).

| Style family | Use for | File |
|---|---|---|
| **Experimental title music** | TV openings and title sequences of 30–90 s that feel strange, sick, unsettling, tense; voices and noises as music; odd meters; "infected" orchestras | `references/title-experimental.md` |
| **Cinematic and hybrid** | Emotional orchestral score, orchestra plus an electronic layer, slow-building arcs, restrained trailer, sci-fi drama | `references/cinematic-hybrid.md` |
| **Dark synth and cyberpunk** | Analog synths, night city, neon, pulsing sequencers, dystopia; synthwave as its bright variant | `references/dark-synth.md` |

More families will come (neoclassical and minimal piano, ambient and drone, suspense). If the user's style is not here, use the closest file for its method and say what you are borrowing.

## A style is a vocabulary, not a recipe

The files describe families, not the piece in front of you. The user's brief and the world of their reference decide; a style file only offers moves. Two things to watch:

- **Don't apply a file because the format matches.** "TV opening" does not mean "experimental title music": a sick, grotesque opening and a clean, unsettling one need opposite palettes. Read what the user wants to feel first, then take only the moves that serve it, from one or several files.
- **Don't reuse the devices of the last piece.** If a figure worked in another song, it is not part of this one's identity.

## How to use a style

1. **Name the style back** in one line with the 3–4 techniques you will use. If the user gave a reference, list what you take from it (techniques), never its melodies.
2. **Check the clichés list before handing back the first draft.** Ask: which neighbouring genre could this be mistaken for? Remove the specific elements that cause it.
3. **Mix families on purpose.** Many real requests are hybrids (an experimental opening with an orchestral core; a cyberpunk cue with a solo cello). Take the structure from one and the colour from the other, and say so.
4. **Plan the final sound.** Placeholder sounds are fine; annotate what each track should become in the user's tools (Vital, Serum, Kontakt…), so the writing serves the real sound.
